# Interactive demo (React artifact)

`mindcare-ng.jsx` is the single-file React demo of the same system, built to run
as a Claude artifact (Tailwind core classes, recharts, lucide-react, keyless
in-artifact Anthropic API). It shares the exact escalation logic with the PHP
build — the `tests/` suite in the repo root and the JS suites were kept in
lockstep during development.

Use it as the quick visual demo; the PHP app in the repo root is the deployable
implementation matching the report's Chapter 3.7 stack.
